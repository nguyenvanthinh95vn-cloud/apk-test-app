# Choi NES

App Android gia lap NES (chay game .nes) viet bang Kotlin thuan.

- Mapper 0 (NROM), 1 (MMC1), 2 (UxROM), 3 (CNROM), 4 (MMC3)
- Tay cam cam ung: D-pad, A (nhay), B (ban/chay), TA/TB turbo ~12 lan/giay, Start/Select
- Ho tro tay cam roi Bluetooth/USB (phim cung, can analog, hat; X = turbo B, Y = turbo A)
- Luu/tai nhanh (save state), luu pin (battery RAM) cho game co ho tro
- Am thanh: 2 kenh pulse + triangle + noise qua AudioTrack 44100 Hz
